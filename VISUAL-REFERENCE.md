OWN-WORLD: Undertow-like charcoal surface (#0c0e11), lifted graphite cards, 12px corners, hairline slate borders, ice-blue emphasis with sand/rose companion series, outline Lucide icons. Light mode translates the same hierarchy. The host still owns light/dark preference. Recursive is the reference's Latin variable face; Chinese uses the platform CJK sans. Bundle the unmodified open-source font and its OFL, with no runtime font request. Reuse maintained OpenUI charts and icons; no new chart engine or copied Empryo application source.

STORY: read the unchanged report, compare the original numbers in compact figures, inspect qualifications and exact cells, then return to the report. Explicit approximation and exclusion notices remain readable.

FIRST VIEWPORT: restrained source label, readable report heading and prose. An encountered table opens into one or several compact graphite figures: icon/title/period in the header, chart in the body, qualifications and original cells in the footer. The unchanged complete table has a clearly labeled disclosure. At narrow widths cards stack without page overflow.

FORM: user-pinned Empryo card-and-focus language; direct code-led adaptation within DSH, no alternative concept round. Node/link treatments may express actual source relations only; numerical tables do not invent graph edges. Keyboard focus receives the same visible treatment as pointer focus; reduced motion disables transitions.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.

Acceptance: unchanged real report still selects seven figures from five tables, source/data qualifiers retained; actual browser light/dark at 1280/400 CSS px plus the user's wide desktop; shared raw/comparison controls; scoped styles and disposal; build, focused UI tests and final required gate; installed official DSH acceptance where user interaction permits.
