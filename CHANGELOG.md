# Changelog

## 0.1.0-preview.1 — 2026-11-01

First public prebuilt preview of the independent intelligent UI plugin.

- Source-preserving assistant/tool presentation, selectable themes and background transparency.
- Built-in offline Uiverse component lookup, silent frontend-development skill and source-backed content adapters.
- Optional report research workspace with judgments, conditions, evidence navigation, comparisons, human notes/review and editable copy-only follow-up drafts.
- AI organization starts only after explicit inline confirmation and follows the current session's permissions and selected model. Ordinary rendering makes no model call.

Compatibility: DSH 0.2.1-rc.2 on macOS arm64. This preview does not modify the official app or other plugin packages. Formal Desktop acceptance of this exact preview and real-model organization remain pending; deterministic scratch Host/Agent and browser checks cover the implemented paths. Existing two-package Uiverse installations must remove the old companion through the normal plugin manager before enabling the integrated package.
