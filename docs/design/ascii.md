# ASCII presentation

User-approved scope, 2026-11-02: a selectable flagship style alongside Empryo, with direct theme selection in the conversation header. No changes to the official app or another plugin's code.

## Direction

- **Thesis:** precise source data becomes a character-based reading surface, with exact text always available.
- **Own world:** graphite ground, pale green emphasis, bundled Recursive's true monospace axis, restrained rounded frames and character plots. This is the user's explicitly requested ASCII direction; it does not replace Empryo.
- **Story:** read the answer, inspect a source-derived comparison, expand its original data, continue reading. Theme selection stays next to display and transparency controls.
- **First viewport:** existing conversation content and controls, with a new compact theme selector. No new landing page, sidebar or decorative metrics.
- **Form:** pinned ASCII direction, code-led extension of the existing theme system. Character bars share a global scale across pages; negative and zero values remain honest. Temporal lines retain the existing renderer and its actual-time/gap handling.

## Acceptance boundary

1. Built-in ASCII can be selected from settings and the header; downloadable JSON uses a versioned, validated, data-only schema. Empryo remains the default.
2. Source-derived bar charts use actual ASCII character plots with exact values, units, qualifiers and data disclosures. Unsupported plots retain the existing faithful renderer.
3. Conversation, tables, graph nodes, controls and compatible existing pages inherit consistent theme tokens. Only plugin-owned CSS/adapters change; disabling/unloading restores the existing cascade.
4. Eligible GLB models use the existing ASCII Object adapter under this theme; raster evidence and factual body text are never distorted by a visual effect.
5. Theme switching preserves source strings and disclosure state. Transparency controls and revision-checked save/error behavior remain available.
6. Verify rendered output at 1280px and 320px, actual switching, error/disabled states and source preservation. Browser proof is distinct from centralized official Desktop installation acceptance.

Screenshots and private reports stay outside Git. The implementation does not claim general Asciify HTML coverage or that all charts become character plots.
