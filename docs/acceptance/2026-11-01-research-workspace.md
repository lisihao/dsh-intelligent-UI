# Research workspace candidate acceptance — 2026-11-01

## Scope and disposition

This candidate adds an optional, current-report research workspace to the existing independent UI package. Six components cover judgments, conditions, source evidence, technical comparison, alternative/challenging material and open questions. AI organization requires an explicit inline cost confirmation and uses the visible current-session queue. Follow-up questions produce editable copy-only drafts.

Source/build, deterministic scratch Host and browser checks passed. **Formal Desktop installation and real-model acceptance remain pending.** Installation belongs to the centralized installer; this task did not change the official app, its desktop profile or other plugins. The package version remains the existing development version; this is not a marketplace release.

## Verified behavior

- Quote-only submissions resolve to unique exact report spans. Ambiguous quotes, incorrect positions, invented or unsafe URLs, wrong sessions and mismatched report identities fail visibly.
- Revision conflicts, atomic persistence, idempotent completed receipts and uncertain-submission handling protect user annotations. Revisiting an archived exact report hash restores its prior analysis and human state; changed text cannot silently reuse an active request.
- Notes and human review marks survived browser reload. AI relationships remained labelled unreviewed; human review remained separate.
- Comparable synthetic A/B rows produced a chart with units and conditions. A differently conditioned C row remained in the complete original table and was not mixed into the chart.
- Citation and comparison-cell actions opened the source inspector. Returning to a table opened its complete raw data. When the renderer provided only a table marker, the UI explicitly disclosed table-level location rather than claiming an exact row highlight.
- The narrow inspector used an opaque surface while preserving 53% report transparency. It did not overflow the viewport. Escape closed it and restored focus to the source control.
- Follow-up drafts were editable and offered copying, with no automatic send action. Browser clipboard writing was not exercised; component tests covered the copy action.
- Disabling research mode restored the mounted report. Unified raw mode retained every original data row.
- The explicit organization confirmation completed against the actual durable store through a deterministic local submission. No external model/provider response was used for this browser check.

## Remaining acceptance

The centralized installer must reconcile the prior install receipt, update only the UI package through the normal plugin manager, preserve current theme/opacity and unrelated plugin locks, and verify the running Desktop. No installer should infer permission for a paid model call from this deterministic acceptance record. Actual selected-model organization, tool availability under the user's session policy and native Desktop behavior require separately recorded evidence.

This slice does not implement cross-session topics, autonomous research, cross-report change analysis or scenario simulation. Report URLs are references contained in the supplied text; their external pages are not fetched or authenticated as evidence. A normal session request follows existing Host permissions and is not a new isolated research engine.
