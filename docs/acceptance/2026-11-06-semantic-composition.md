# Source-bound semantic composition acceptance — 2026-11-06

## Scope

The default-off block-layout experiment and configurable shortcut are retained. Automatic theme descriptions no longer include a default material. Every block has an actual ThemeCard surface, so native, soft-relief, clear-glass and mechanical-outline describe the same applicable surface, including prose, code, tables and relationships. Descriptions state real visual affordances and costs without requiring form controls.

The rubric protects facts, values, units, qualifications, uncertainty and meaningful procedure/time order while allowing registered visual grouping and validated numeric projection. It does not require the original page geometry. No diversity quota, option-order manipulation, score adjustment or forced chart selection was added. Complete source remains available once in the model context; question descriptions are not duplicated in another catalog.

Two new executable organizations arrange complete existing unordered source items: `source-list-grid` and, for explicitly labelled single-paragraph items, `source-label-table`. They move existing AST nodes with exact source ranges, retaining inline code, links, footnotes, non-list content and qualifications. They do not invent labels or summarize arbitrary narrative paragraphs. Cards and disclosure continue to be described honestly as whole-block treatments.

Chart choices carry their actual chart type, category/value mapping, source headers, units, sampled points with original cell strings, source rows/columns and excluded totals/fields. Sampling currently limits point/example lists to eight; it does not bound all notes, plans or whole requests. The supported `CAD 百万` header retains values without conversion. Unrecognized currency scales are declined. Chart-note extraction respects supported headings and local list/paragraph boundaries; explicit table-note qualifications remain applicable. This shared parser correction also affects the nonexperimental route.
