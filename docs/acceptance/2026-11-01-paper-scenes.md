# Paper scene composition: preview acceptance

## Boundary

The user rejected the first Paper adaptation and explicitly allowed long argument to collapse behind “展开本节正文”, while figures, units, periods and key qualifications remain visible. This record covers the revised independent UI-plugin browser prototype. It does **not** claim this revision was installed in formal DSH. The previously restored application was not quit, restarted or modified during this round. No host or foreign-plugin file was changed.

The changed paths are the Paper structural renderer and its scoped styles, the source-plan chart stage, Paper tests, the locally bundled open-source display font and the corresponding design/build/notices documents. Other themes retain their existing topology.

## Implementation

- An arched title plane, shared faint canvas frame/grid, intersection handles and diagonal chapter transitions replace the ordinary split-copy layout.
- A full-width primary figure, visible qualifications and complete source-paragraph captions organize each source topic. Remaining long argument has a local native disclosure. No source node is summarized or lifted across a subheading.
- Multiple source plans use actual title/basis tabs, retained hidden panels and optional explicit five-second demonstration playback. Playback stops for manual input, suspends in the background and is disabled for reduced motion. Each plot retains its scale; a permanent note warns against comparing bar lengths across periods/units.
- The foreground exact-data window uses reserved space below the plot and beside the notes; narrow layouts stack it. Narrative scenario/research tables reuse the existing read-only list/detail component. Narrow selection and fields are vertical.
- Unmodified DM Sans Latin 5.3.0 and its OFL are bundled locally. No commercial Matter font, Paper animation, logo or music artwork is distributed.

## Limits

This is a faithful adaptation of the requested scene hierarchy using real report content; it is not the Paper editor, its commercial font or a pixel-identical copy. Deterministic caveat detection cannot certify the meaning of arbitrary prose; complete original content remains authoritative. Dynamic plots use independent axes with visible guidance. Native installed-app acceptance remains separate from browser-preview acceptance.
