# ASCII theme and conversation theme switching

## Candidate boundary

This development candidate adds the built-in/downloadable ASCII theme alongside default Empryo, a conversation-header theme selector, responsive source-derived ASCII categorical bars and theme-selected ASCII Object for validated GLB models. It changes only this independent UI plugin. It does not modify the official application, other plugin packages or source sessions.

V1/V2 themes remain compatible. V3 selects a compiled ASCII grammar through strict JSON; it cannot supply code, CSS or remote assets. Mixed units, non-finite values and temporal lines keep the existing renderer. Raster evidence and ordinary factual text are not distorted.
