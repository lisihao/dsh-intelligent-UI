# Real WebGL ASCII graphics candidate

The user rejected the earlier character-bar theme and requested actual Canvas UI-style ASCII graphics. This candidate replaces the selected CPU bar path with an automatic graphics projection using the unmodified, pinned upstream Asciify factory. Validated illustrative PNG/JPEG and GLB also use ASCII Object; the explicit original-image region remains native. No other plugin or official application source changed.

## Scope and evidence

- Original OpenUI geometry supplies bar, line, pie, radar and scatter plots. SVG text, numerical labels, DOM hit targets, source values and the existing raw/compare path remain native. Unsupported sources retain their original display.
- SVG capture handles actual visible overflow and local diagram markers; the browser check caught and repaired the React Flow 300×150 viewport that previously cropped both arrows. The owned graph renderer publishes its actual just-drawn frame, avoiding asynchronous reads of discarded WebGL buffers.
- A shared viewport atlas uses real Asciify shader output, with scale 0.5, brightness 0.09 and contrast 1. Actual browser renderer: ANGLE Metal on Apple M4 Pro. The browser check covered 1280×900 and 320×880, real pointer/input/rotation, source-preserving theme roundtrip, real context loss and explicit retry by theme switching.
- Lifecycle/policy checks cover stale async captures, source and viewport changes, popup occlusion, opacity, pointer/focus overlap, failed-frame retry loops, resource release and protected original images. Image and CSS-animation snapshots update at a bounded 5 Hz; offscreen SVG/image copies are released. This is not a frame-rate performance claim.
- Initial full-suite evidence was 813 passes and 3 existing skips. Subsequent source changes were checked through the affected integration set, including 150 final affected tests; TypeScript, build and source-design checks passed. Exact packed candidate i passed the disposable published-DSH built Host/Agent test, including persistence/restart and disposal, with zero live model calls.
- A private original report's complete raw string matched its unchanged 22,777-character source hash. It was replayed without research or a model call. Independent visual review returned `ship` for the local candidate and the ASCII Object addon.

## Explicit limits

Arbitrary foreign canvases, opaque iframe/shadow content, unsupported SVG/image effects and ASCII Sweep are not claimed. Glyphs are a visual approximation; exact source data remains authoritative. The browser test is not official Desktop acceptance.
