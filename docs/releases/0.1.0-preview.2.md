- [NOAA Mauna Loa CO2](https://gml.noaa.gov/ccgg/trends/data.html): the first 10,000 actual observations, 1974-05-19 through 2007-11-18, ppm. Calendar gaps were retained without imputation; overview, selected-range detail and the final raw-data page passed.

The native WebGL2 overview and background ELK layout completed; exact search, one-hop direction and the final source node/edge passed.
- Derived counts within that same subset: 1,000 categories, a total count of 5,000 and three real zero counts. Source-order paging passed. These are sample-only counts, not global citations or quality rankings.

All three stored raw-text SHA-256 values equaled their supplied files. The original 361 UI-owned files and other plugin sources were unchanged at the end of this UI installation stage. Original/display and session switching retained the imports. Private native captures and receipts remain outside Git.

## Compatibility and limits

DSH **0.2.1-rc.2**, macOS arm64. Configured artifact byte/count limits still apply. Large graphs omit tiny overview labels; readable neighborhoods and complete source pages retain the underlying records. Native GPU-context-loss, 388px native width and disable/re-enable were not rerun on this candidate; browser and historical lifecycle evidence remain separate. Real-model research organization and the 3D terrain concept are not claimed as accepted or implemented here.

Download the `.tgz` and `SHA256SUMS` Release assets, then use the normal official plugin manager with lifecycle scripts disabled. Preserve settings, themes, opacity, sessions and credentials; installation/restart remains centrally coordinated. Earlier standalone Uiverse companions must be disabled/removed through the normal plugin manager before the integrated package is enabled. The official app and foreign plugin packages are not patched.

The existing community-market entry remains valid. Its download URL must be updated through the catalog maintainer workflow; publication of a GitHub Release does not prove that a cached marketplace already offers this version. npm publication is not required.
