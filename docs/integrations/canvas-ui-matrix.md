# Canvas UI component progress

This is an implementation and evidence ledger for the 35 components at Canvas UI commit `a04a99b235299ee79a123a16ccb2e6cf9da74b6b`, not a claim of complete support. Original data and the independent-plugin boundary are mandatory. The upstream MIT + Commons Clause license remains in force.

Official Desktop candidate `52e26952…` rendered source-declared GLB with Ink, ASCII and Glass and a structured JPEG with Ink and its original image. Its Markdown `data:` PNG generated Ink but failed to display the adjacent original; source text remained intact. Candidate `4786545f…` fixed that original and passed Desktop display plus uninstall/reinstall checks on the same PNG; local browser checks covered 1200 and 320 CSS pixels, including reduced motion. Candidate `5a42ff3b…` was installed and passed PNG, existing GLB, original mode and disable/restore checks, while its HTML adapters and no-domain automatic selection lacked a normal Desktop consumer for acceptance. Subsequent adapter additions in this source are not yet installed. The HTML experiment below ran in isolated Chrome 156 using SwiftShader and an exploratory snapshot shim. It does not prove hardware acceleration, DSH Chromium 152, complex layout, text/data fidelity or interaction parity. No HTML effect is automatically applied to ordinary report data or code.
